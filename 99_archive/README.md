`history.zip` 按资料类别保留内部路径，`entries.json` 记录逐项 SHA-256。旧源码归档不包含可重建环境和重复权重，恢复时按来源记录准备依赖，并从当前模型目录校验补齐 checkpoint。

记录反映各次整理时的路径，当前入口以本页为准。归档包含原始连接记录，公开发布前应单独审查敏感信息。

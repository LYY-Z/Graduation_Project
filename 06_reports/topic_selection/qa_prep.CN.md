# 汇报问答准备（自用，不交给老师）

| 可能的提问 | 回答要点 |
|---|---|
| 创新是不是只把一个系数改成几个？ | 只改系数，推理时会出现训练没见过的组合，效果可能更差。核心是"部分信息可信条件下的鲁棒训练"，并用"分组不退回""整体退回""直接告知可信组"等消融说明改进来自哪里 |
| 为什么不选级别更高的 PACE 或 TAM？ | PACE 的运动训练环境未公开，延伸到轮地参数偏工程，作为保底；TAM 前提是固定基座、无接触、有理想逆动力学，作者自己指出接触会被误判，Go2-W 不满足 |
| 为什么不选和 Go2-W 最契合的 MoE-CTS？ | 它的贡献偏策略评价与筛选，需要策略池和大量实机重复；本课题希望直接改进控制 |
| 为什么不用 AugMPC？ | Go2-W 没有现成的轮足 MPC，自建需 2–4 个月；论文本身没有对比基线与扰动实验 |
| GRAM 代码能直接跑吗？ | 不能。需从 Isaac Lab 1.0 迁移；没有权重和运行中变化的实现，需要自己补 |
| 为什么不直接用域随机化？ | 作为对比组，在相同训练范围和预算下比较 |
| 为什么不用传统控制？ | 传统容错方法作为对比组，不预设学习方法更好，按变化类型分析适用情形 |
| 因素分不开怎么办？ | 第 2–4 周的上限检验先判断"分开是否有用"；实际分不开时报告可区分的边界，转为 GRAM 复现与失效分析 |
| 老师推荐的 LocoFormer、TAM 等为什么没用？ | 见报告第四节：LocoFormer 无代码、算力需求大；TAM 只适用于固定基座机械臂 |

## 2. 基础论文精读：Random Joint Masking

*Learning Quadrupedal Locomotion with Impaired Joints Using Random Joint Masking*。Mincheol Kim、Ukcheol Shin、Jung-Yup Kim（首尔科学技术大学、CMU）。**ICRA 2024**，pp. 9751–9757。依据 arXiv 2403.00398v1 全文逐页阅读。**代码未开源。**

| 环节 | 内容 |
|---|---|
| 作者的问题 | 【作者】四足机器人关节受损（外力撞击或内部故障）后无法行走，甚至摔坏。目标是用**单个网络**让机器人在正常和关节受损两种情况下都能行走（p1）。故障类型：零力矩（无力）和锁死（p1–2）。平台为 Unitree Go1（12 自由度）；任务是跟踪前向速度指令和原地转向（p5） |
| 已有局限与挑战 | 【作者】已有容错多为简单的倒地恢复；模型方法要精确模型，每种故障单独建模调参；已有 RL 容错只在仿真中评估且不公开（p1–2）。挑战：①策略随损坏位置和状态而变，例如髋外展关节无力会让整条腿失去全部自由度，膝关节锁死则保留大部分自由度（p1）；②单网络学多种策略会灾难性遗忘，各故障表现不均衡（p4） |
| 方法设计 | 基于 legged_gym 并行 PPO、特权信息的教师—学生蒸馏、Walk-these-ways 的奖励与步态（p3）。新增三项机制，各对应一个挑战：①**随机关节掩码**：把被指派关节的期望力矩和动作置零来模拟故障（Eq. 2–3），解决训练中缺少故障数据；②**关节状态估计器**：教师用特权信息（摩擦、恢复系数、哪个关节坏了）生成隐变量，学生从最近 30 步观测历史中回归它（Eq. 4），解决"要知道哪个关节坏了"；③**渐进式课程**：从正常开始，依次加入膝、髋俯仰、髋外展故障（Alg. 1），解决灾难性遗忘 |
| 任务与训练 | 观测 62 维：关节角与速度、重力方向、落足位置、指令、当前与上一步动作；动作 12 维关节目标角度，经 PD 转为力矩（p6）。部署时只用学生估计器与策略，不需要故障标签，无微调直接上真机（p5） |
| Benchmark | 仿真 Isaac Gym；真机室内用 OptiTrack 动捕，室外用 RTK-GPS，两条路线共 0.5 km（p5–6）。故障**只有单关节**，位于前左和后右腿的三个关节，类型为无力和锁死（表 II、III）。测试故障与训练同类，**未测未知故障或多关节故障** |
| Baseline | 未改动的 legged_gym 策略，以及逐步加入各机制的消融（表 II）。作者称其他 RL 容错方法不公开，无法比较（p5）。【评价】基线训练时没有见过故障，失败是预期结果，**不是对等的容错对手** |
| 实验与指标 | 仿真：1.0 m/s 前进指令下的速度跟踪 RMSE。平均 RMSE：基线 0.5787，只加掩码 0.3662，加掩码与估计器 0.2529，完整方法 0.1951（表 II）。真机：正常前进 1.35 m/s；前左腿无力时 1.14 m/s，锁死时 1.01 m/s（表 III）。**无重复次数、无随机种子、无方差** |
| 贡献与局限 | 【作者】贡献为三项机制；局限是性能随损坏位置下降，仍有很大改进空间（p6）。【评价】优点：机制简单通用，有真机验证。不足：①只覆盖单关节，故障位置在训练时被枚举；②无统计；③基线弱；④真机无基线量化；⑤以平地为主 |
| 复现要点 | 【评价】难度中等偏低：在 legged_gym / Isaac Lab 上改动量小。但**超参不齐**：课程阈值、PPO 参数、网络结构等都没给，要自己设定。迁到 Go2-W：维度从 12 扩到 16；轮子是速度控制，"锁死"等于拖地，"无力"等于自由滚动，与腿关节含义不同，需单独设计；步态相位奖励对轮足不适用 |

## 3. 研究方案

### 3.1 研究问题与挑战

**问题**：Go2-W 运行中发生电机失效时，能否只依靠机载本体感觉判断故障，并利用剩余的腿和轮，跨运动方式继续完成任务？

**挑战**：
1. **故障含义因执行器而异**：轮子锁死等于拖地，轮子无力等于被动滚动；腿关节无力会失去支撑，卡死会限制步态。不能简单照搬腿式机器人的"关节置零"。
2. **不知道哪里坏了**：部署时没有故障标签，只能从运动表现中推断。
3. **何时切换运动方式**：轮坏改走、腿坏改滚，切换的时机和方式需要学习，固定规则难以覆盖各种故障与地面。
4. **单策略学多种应对方式**：存在灾难性遗忘（基础论文已指出）。
5. **实机安全**：腿关节失效会失去支撑。

### 3.2 针对性设计【设想】

| 挑战 | 设计 |
|---|---|
| 故障含义不同 | 为轮、腿分别定义故障模型：轮锁死、轮无力、腿关节无力、腿关节卡死；训练中按时间随机注入 |
| 不知道哪里坏了 | 历史编码器从本体感觉推断故障（RMA 式），与带真实故障标签的上限版本对比 |
| 何时切换 | 策略的动作同时覆盖腿和轮，可在滚、走、混合之间转换；奖励包含任务完成与稳定性 |
| 灾难性遗忘 | 沿用并扩展基础论文的渐进式课程，加入轮故障 |
| 实机安全 | 先做轮失效（最安全），腿关节失效在悬吊保护下进行 |

### 3.3 任务、基线与指标

**任务**：沿固定路线以指令速度行驶，途中按预定时间注入单个电机失效；另做原地转向测试。

**基线**：

| 组 | 作用 |
|---|---|
| 默认 Go2-W 策略（无容错） | 下限 |
| 传统容错：模型残差检测故障 + 规则切换模式 | 传统控制基线 |
| Random Joint Masking（复现，扩到 16 自由度） | 已有学习方法 |
| GRAM（通用鲁棒适应，RA-L 2026） | 检验专门针对故障的设计是否必要 |
| 带真实故障标签的容错策略 | 上限 |
| 本文方法 + 消融（禁止模式切换 / 去掉历史编码器 / 去掉课程） | — |

**指标**：路线完成率、速度保持率（故障后 ÷ 故障前）、偏航漂移、摔倒次数、故障后恢复时间、整机能耗（母线电压 × 电流）。

**统计**：每个条件 3 个训练种子 × 每个种子至少 5 次真机，配对、随机顺序，报告均值、标准差和置信区间。这一点补上了基础论文没有重复实验的不足。

### 3.4 与传统控制的关系

1. 容错控制是控制领域的经典方向：先检测与隔离故障，再重构控制律。本方案把这一套作为基线放进实验。
2. 学习方法的潜在优势：故障类型与地面组合很多时，不需要为每种故障单独建模和设计切换规则。基础论文也指出，模型方法每种故障都要单独调参。
3. 本方案**不声称**"学习优于传统控制"，而是在同一平台、同一组故障下比较各自的适用情形。

### 3.5 时间计划与关卡（约 16 周）

| 周 | 内容 | 关卡 |
|---|---|---|
| 0 | 确认底层控制权限、能否用软件安全屏蔽单个电机、悬吊保护、场地 | 不能屏蔽电机 → 换保底 |
| 1–3 | 训练 Go2-W 基础滚/走策略并上真机；仿真中注入各类故障，测默认策略的退化 | 故障确实造成明显退化，否则问题不成立 |
| 4–6 | 复现 Random Joint Masking（16 自由度）；实现传统基线 | 复现完成 |
| 7–10 | 本文方法与消融（仿真） | 仿真中明显优于基线，否则收窄到"单轮失效"做深 |
| 11–14 | 真机：先轮失效，再在保护下做腿关节失效 | — |
| 15–16 | 写作（第 13 周前完成保底版） | — |

### 3.6 风险与应对

| 风险 | 应对 |
|---|---|
| 被抢先：IIT 已点名此方向 | 尽早开始，先拿出"单轮失效 + 跨模式补偿"的实机结果 |
| 某些故障影响太小，例如轮无力时被动滚动 | 第 1–3 周先测，只保留确实造成明显退化的故障 |
| 基础轮足策略训练不稳 | 先用 rl_sar 自带策略验证流程；故障类型收窄 |
| 腿关节失效时机身失去支撑 | 悬吊保护、低速、两人看护 |
| 基础论文无代码、超参不全 | 方法简单可自写；IIT 公开的 Isaac Lab 容错代码（预印本）作参考 |

**措辞**：不写"首次实现足式容错"。可写"将学习式容错扩展到轮足平台，利用轮—腿跨模式冗余补偿执行器失效"，并限定在检索范围内。中文文献与 IEEE 原生检索在投稿前补查。

## 4. 老师可能问的问题

| 问题 | 回答要点 |
|---|---|
| 足式容错已经很多了，你的创新在哪？ | 已有学习式容错全部在纯腿机器人上做，且以单关节为主。轮足多了一套运动方式，可以跨模式补偿：轮坏改走、腿坏改滚。这是纯腿和纯轮机器人都没有的研究空间。IIT 2026 年的论文也把它列为未来工作 |
| 为什么之前没人做？ | 轮足的学习控制本身只有约两年积累，顶会中轮足只占 2%；强课题组刚把它列为下一步。属于新机会，不是没价值 |
| 为什么不用传统容错控制？ | 传统方法作为基线放进实验。学习方法的优势在故障与地面组合多时，不需要逐一建模和设计规则。最后用数据比较 |
| 基础论文没有代码，怎么复现？ | 方法简单：随机掩码、教师—学生估计器、课程。可在 Isaac Lab 上自写；超参缺失的部分自行设定并在论文中写明 |

## 5. 请老师确认

1. 题目方向：利用轮—腿冗余的轮足容错运动控制。
2. 保底（轮—地标定对齐）与备选（腿姿协同转弯）是否保留。
3. 实验条件：用软件屏蔽电机是否允许；悬吊保护；场地与每周的实机时间。
4. 对传统容错基线的具体要求。

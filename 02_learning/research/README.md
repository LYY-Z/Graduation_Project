`evidence/` 保存公开来源与目录记录；`tools/` 保存发现、核查链接的工具。这些记录不代表完成了每篇全文精读，也不代表已穷尽研究领域或完成性能复现。官方发布情况、版本条件和候选排序应随新证据持续更新。

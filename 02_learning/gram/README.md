# GRAM 学习手册

**论文**：Queeney et al., *GRAM: Generalization in Deep RL with a Robust Adaptation Module*, IEEE RA-L 11(2):2218–2225, 2026。原文：[GRAM.pdf](../../01_papers/research/GRAM.pdf)；代码：merlresearch/gram。

## 一页看懂 GRAM

**问题**：用强化学习训练的四足策略，在训练见过的情况（ID）下要能针对性适应，在没见过的情况（OOD）下要能稳住。适应型方法（教师—学生 / RMA）ID 好、OOD 会"估错还很自信"；鲁棒型方法（对抗训练）OOD 稳、ID 太保守。

**方法**：
1. **教师—学生**：仿真里用真实环境参数训练策略，再训练一个适应模块从 16 步运动历史估计环境；
2. **epinet**：适应模块带一个小网络和随机输入，同一历史算 8 次，结果越分散，说明越"没见过"；
3. **软切换（式 9）**：可信度 α = exp(−λ(不确定性 − β)⁺)，输出 = α·估计 + (1−α)·0；
4. **z_rob = 0 是一个专门训练过的鲁棒点**：训练时一半环境用真实参数正常训练，一半环境输入 0 并加推力对抗者，同一个网络学会两种模式，迭代之间交替。

**结果**：仿真 ID / 近 OOD / 远 OOD = 0.92 / 0.79 / 0.58，ID 接近情境 RL（0.94），远 OOD 接近鲁棒 RL（0.59）；实机困难场景 15/15（鲁棒 RL 12/15，情境 RL 2/15）。

**我们关注的局限**：不确定性是**一个标量**，一不确定就**整体**退回；鲁棒训练只有推力一种；没测电机变弱或失效。

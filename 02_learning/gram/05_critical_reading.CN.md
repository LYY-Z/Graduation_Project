# 05 批判性阅读：GRAM 的贡献、局限与可改进点

本篇回答老师最可能问的三类问题：
1. 这篇论文**真正新在哪里**？（"老问题、新方法"的标准）
2. 它**有什么不足**？哪些是作者承认的，哪些是我们读出来的？
3. 从这些不足出发，**能做什么改进**？

标注：**【作者】** 原文写的；**【我们】** 我们的判断；**【代码】** 读官方代码得出。

---

## 1. 用"老问题、新方法"拆解 GRAM

| 层次 | 内容 | 新不新 |
|---|---|---|
| 问题 | 动力学变化下的控制：既要针对性适应，又要对没见过的情况鲁棒 | **老**。控制里叫鲁棒自适应控制，至少有 40 年历史 |
| 基础框架 | 教师—学生（RMA 类）+ PPO + 对抗训练 | 老（2020–2024 年的已有方法） |
| 不确定性工具 | epinet | 老（Osband 2023 已提出） |
| **把认知不确定性用作"适应 ↔ 鲁棒"的切换信号** | 式 (9) | **新** |
| **把鲁棒模式嵌入隐空间的一个点（z_rob=0），两种模式共用一个网络** | 同一 π(a∣s,z) | **新**，也是最巧妙的地方 |
| **联合训练 + 迭代间交替的混合数据收集** | Alg. 1 | **新**（组合方式新），消融证明有效 |
| 用验证集分位数自动定标 β、λ | Sec. VI | 实用技巧 |

**【我们】一句话评价**：GRAM 没有发明新的零件，它的新在于**组合方式**：用机器学习里的认知不确定性，把控制里"适应"和"鲁棒"两条老路线接到同一个网络里，并给出了一个能训练出来的方案。这正是"老问题 + 新方法"的典型。

### 和 2025–2026 年同类工作的对比（老师可能问"同期别人怎么做"）

| 思路 | 代表 | 和 GRAM 的区别 |
|---|---|---|
| 更强的隐式辨识 | HIMLoco（ICLR 2024）、DreamWaQ | 只提升 ID 适应，没有"不可信时退回"的机制 |
| 多专家 / 多策略 | MoE-CTS（RSS 2026）、Walk These Ways | 多个策略或专家切换，GRAM 是单网络软混合 |
| 安全切换到恢复策略 | ABS（RSS 2024） | 硬切换两个独立策略，对应 GRAM 消融里的 Modular |
| 超大规模历史上下文 | LocoFormer（CoRL 2025） | 靠规模让模型自己学会适应，算力需求大约高 500 倍 |
| 显式系统辨识 | PACE（IJRR 2026） | 实机数据辨识参数，从源头缩小差距，和 GRAM 互补 |

## 2. 作者承认的局限

**【作者】**（Sec. IX）
1. OOD 泛化依赖于鲁棒训练能多好地覆盖最坏的 OOD 动力学，**极端 OOD 可能失败**；
2. 只用了**一种标准对抗者**（推力），值得结合其他鲁棒 RL 技术；
3. 只在**四足**上验证，可以扩展到其他机器人和任务；
4. 领域知识可以通过**上下文集的选择**和**对抗者的选择**引入。

## 3. 我们读出来的不足

按"方法 / 实验 / 代码与复现"分三类。每条给出依据，以及**它是否构成可做的研究点**。

### 3.1 方法层面

| # | 不足 | 依据 | 能否作为研究点 |
|---|---|---|---|
| M1 | **不确定性是一个标量，退回是整体的。** 8 维方差求和成一个数，α 对整个隐变量统一缩放。只有一个因素陌生时，其他仍然准确的估计也被一起丢掉 | 式 (7)(9)；代码 `var(dim=0).sum(dim=-1)` | **能，主线**。改成按物理因素分组的不确定性和分组退回 |
| M2 | **隐变量没有物理含义。** 8 维 z 是 26 维上下文的压缩，哪一维对应摩擦、哪一维对应电机，并不清楚。所以即使想分开判断，也无从下手 | 上下文编码器是普通 MLP | 能，是 M1 的前提：需要"分块"的上下文编码器 |
| M3 | **鲁棒训练只有一种扰动（推力）。** 但测试的 OOD 有加重、坡、地形、关节冻结。为什么推力练出的鲁棒性能泛化到这些，论文没解释 | Sec. V；作者局限 | 能。对执行器类扰动（电机变弱、失效）做专门的鲁棒训练 |
| M4 | **中间 α 值的 z 训练时从没出现过。** 训练时 z 要么是 f(c)，要么是 0；部署时是 α·μ̂，落在两者之间。为什么策略在这些点上也表现合理，没有分析 | 式 (9) vs Alg. 1 | 可作为分析点；分组后这个问题更突出，需要训练时就引入"部分置零" |
| M5 | **没有稳定性或性能保证。** 全靠实验 | 全文无理论分析 | 本科阶段不建议碰，但要能回答 |
| M6 | **历史只有 16 步（0.32 s）。** 匀速稳态时激励可能不足，难以分辨某些参数（如电机强度在低负载时） | Table I | 可作为分析点：可辨识性 |
| M7 | **不确定性只能检测"没见过"，不能区分"没见过的原因"。** 例如加重和电机变弱都会让腿更"软"，epinet 只会说"不确定"，说不出是哪个 | epinet 原理 | 能，和 M1 同一方向；这也是分组方案最大的风险 |

### 3.2 实验层面

| # | 不足 | 依据 |
|---|---|---|

| E2 | 近/远 OOD 的四类场景合并成一个平均数，看不到每个场景的表现 | Table III |

**E3 很重要，老师可能会抓**："那 GRAM 的核心模块其实没那么有用？" 建议的回答：
> α 混合在远 OOD 上带来 0.55→0.58 的提升，在近 OOD 上没有提升；鲁棒性的主要来源是联合训练。但 α 的价值不只在平均分，还在于它让**同一个网络**在 ID 下保持接近情境 RL 的性能，并且提供了一个**可解释的"当前可不可信"信号**。Fig. 5 显示它能随训练范围自动调整。我们的改进正是要让这个信号更有用：从"整体可不可信"变成"哪部分可不可信"。

| # | 论文写法 | 代码实际 | 影响 |

## 4. 从不足到改进：可能的研究方向

| 方向 | 针对的不足 | 做法 | 难度 | 新意 |
|---|---|---|---|---|
| **A. 选择性鲁棒适应（主线）** | M1、M2、M4、M7 | 上下文按物理分组（环境：摩擦+负载；执行器：电机强度+零偏），隐变量分块，每组单独估计不确定性和 α_g；训练时随机让某些组"不可信"并置零，同时把这些组的参数推到训练范围外 | 中 | 方法上新：从"整体可不可信"到"哪部分可不可信" |
| B. 执行器类鲁棒训练 | M3、E9 | 除推力外，加入"电机变弱/失效"的对抗或随机扰动 | 低–中 | 偏 A+B 组合；可并入 A |
| **C. 轮足腿轮冗余容错** | E9 + 平台特点 | 在 Go2-W 上把 A 用到执行器失效：轮子卡死/无力、腿关节无力；利用腿轮互补 | 中–高 | 切入点新：纯腿机器人做不到 |
| D. 运行中变化的系统评估 | E4 | 补"中途加载荷/换地面/电机变弱"的事件和响应时间指标 | 低 | 偏评估，可作为 A/C 的实验部分 |
| E. 不确定性方法对比 | E5 | epinet vs 集成 vs MC Dropout | 低 | 偏工程，新意小 |

**推荐组合**：A 为方法主线，C 为应用场景和实机亮点，B、D 作为实验设计的组成部分。三者合起来，正好回应老师的"方法新 + 切入点新"。

### 方向 A 的关键风险（必须提前想好）

| 风险 | 表现 | 应对 |
|---|---|---|
| 因素分不开 | 一个轮子变弱和地面变滑，在 16 步历史里看起来很像，分组不确定性同时升高 | 先做 **oracle 上限实验**：直接告诉策略哪组不可信，看分组退回是否比整体退回好。没有好处就不往下做 |
| 分组后中间状态没训练过 | 部分组置零的 z 组合，策略没见过 | 训练时就随机置零部分组（这正是方案的核心步骤） |
| 只是"一个系数改成几个" | 被认为改动太小 | 强调训练方法的改变（部分可信下的鲁棒训练），并用消融区分"只改推理"和"改训练"的效果 |
| 故障影响太小 | 例如轮子无力时还能被动滚动，退化不明显 | 先测出哪些故障造成明显退化，只研究这些 |

## 5. 读完这篇论文应该能回答的五个"研究者问题"

1. **它解决了什么问题？** 一个策略同时做好 ID 适应和 OOD 鲁棒。
2. **为什么以前做不好？** 适应型方法在 OOD 时估错还很自信；鲁棒型方法在 ID 时太保守；两者分开训练再切换（Modular）效果也不好。
3. **它的关键想法是什么？** 用认知不确定性衡量"估计可不可信"，不可信时把隐变量收缩到一个专门训练过的鲁棒点 0。
4. **证据够不够？** 仿真和实机都支持"两头接近最好"；但统计信息不全，且大部分鲁棒性来自联合训练。
5. **还能往哪走？** 作者说换鲁棒训练方式、扩展到其他机器人；我们读出来的是：不确定性从标量变成分组、针对执行器类变化、结合轮足的冗余。

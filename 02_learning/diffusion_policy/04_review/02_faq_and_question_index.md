# 高频疑问索引：从“我当时不懂什么”到完整答案

## 使用方式

这不是第二本教材。每一项按同一结构组织：

> **疑问 → 最短回答 → 为什么 → 完整复习 → 自检**

如果再次“没看懂”，先在这里定位，再跳到唯一完整解释处；不要在多篇笔记中反复找同一个公式。

## 1. 机器学习、图像与行为克隆

### 机器学习和深度学习有什么区别？

**最短回答：** 二者都从样本调参数；普通机器学习常由人先准备特征，深度学习可从原始像素学习多层特征。  
**为什么：** 机器人画面的组合太多，难以手写完整规则。动作误差的反向传播会保留对控制有用的视觉变化。  
**完整复习：** [ML 与 DL](../01_foundations/01_ml_dl_and_imitation.md#2-机器学习与深度学习的差别)。  
**自检：** 网络是否必须先得到“杯子”这个中文标签才能控制？

### 图像怎么知道哪个是杯子、哪个是机械臂？

**最短回答：** 它不必有物体名称标签；图像—专家动作—噪声预测误差的反向传播会让网络学习物体、末端和相对几何等有用模式。  
**为什么：** 能降低动作噪声预测误差的视觉特征被保留；这不保证它具有人类语义或认识所有新物体。  
**完整复习：** [视觉数据流](../02_paper_study/03_control_network_and_design.md#11-观察动作和网络一条完整数据流)。  
**自检：** “视觉特征有用”是否等于“模型永远认识未知物体”？

### MSE、反向传播和学习率分别是什么？

**最短回答：** MSE 是误差平方平均；反向传播计算每个参数对误差的影响；学习率是每次按该方向更新多大步。  
**为什么：** 平方避免正负误差抵消并更重罚大错；太小的学习率很慢，太大会震荡。  
**完整复习：** [MSE 与学习率](../01_foundations/01_ml_dl_and_imitation.md#4-mse把错多少变成一个数字)。  
**自检：** 为什么误差 \(+2\) 与 \(-2\) 不能直接相加？

### 分布偏移、多峰和多模态输入是不是同一回事？

**最短回答：** 分布偏移是执行偏差把机器人带到示范少见状态；多峰是同一观察有左绕/右绕等多个正确动作；多模态输入是图像和状态等多种输入来源。  
**为什么：** 确定性 MSE 回归可能把左、右两个动作平均到障碍物上。  
**完整复习：** [BC、多峰与分布偏移](../01_foundations/01_ml_dl_and_imitation.md#6-行为克隆从专家演示直接模仿)。  
**自检：** 多峰动作是否等于执行时随机乱动？

### Diffusion Policy 是强化学习吗？

**最短回答：** 它是行为克隆：从专家示范的观察—动作对学习，不以奖励试错为核心。  
**为什么：** RL 问“长期回报最高吗”，本文问“这种观察下专家动作计划像什么”。  
**完整复习：** [BC 与 RL 边界](../01_foundations/01_ml_dl_and_imitation.md#7-bc-与强化学习rl不一样)。  
**自检：** 本文训练损失中有没有环境奖励 \(r\)？

## 2. DDPM：高斯、变量和前向加噪

### 高斯分布是数字吗？噪声怎么加入图片或动作？

**最短回答：** 高斯分布是抽数字的规则；\(\epsilon\sim\mathcal N(0,I)\) 是与图片或动作同形状的随机浮点张量。  
**为什么：** 先逐元素抽数，再按系数逐元素与样本相加；\(I\) 表示各维标准化且独立的理想假设。  
**完整复习：** [高斯不是一个数字](../01_foundations/02_ddpm_from_intuition_to_formula.md#3-高斯分布不是一个数字)。  
**自检：** 若动作计划形状是 \(16\times7\)，\(\epsilon\) 的形状是什么？

### 为什么有平方根？

**最短回答：** \(\alpha\) 和 \(1-\alpha\) 是方差比例；随机量乘 \(c\) 后方差乘 \(c^2\)，所以振幅要用平方根。  
**为什么：** \(\sqrt\alpha x+\sqrt{1-\alpha}\epsilon\) 才让信号与噪声有预期的方差贡献。  
**完整复习：** [平方根](../01_foundations/02_ddpm_from_intuition_to_formula.md#42-为什么是平方根)。  
**自检：** 这里的平方根是美化公式，还是由方差规则决定？

### \(x_0,x_t,\epsilon,z,\alpha,\beta,\bar\alpha\) 分别是什么？

**最短回答：** \(x_0\) 是干净样本，\(x_t\) 是带噪样本；\(\epsilon\) 是训练前向噪声，\(z\) 是反向抽样噪声；\(\beta\) 是新增方差，\(\alpha=1-\beta\)，\(\bar\alpha\) 是累计保留比例。  
**为什么：** \(\epsilon\) 与 \(z\) 分布相同但发生在不同阶段、角色不同。  
**完整复习：** [变量表](../01_foundations/02_ddpm_from_intuition_to_formula.md#2-所有变量到底是什么) 和 [符号卡](01_symbols_and_formula_cards.md)。  
**自检：** \(\epsilon\) 与 \(z\) 是否是同一次采样中同一用途的数组？

### 为什么可以多次加噪，最后仍接近标准高斯？

**最短回答：** 高斯变量加权相加仍高斯；累计信号比例 \(\bar\alpha_t\) 逐渐变小，最后主要剩标准噪声。  
**为什么：** 这给生成一个简单已知的起点，也让训练可以直接构造任意噪声等级。  
**完整复习：** [闭式前向过程](../01_foundations/02_ddpm_from_intuition_to_formula.md#5-多次加噪为什么仍然容易计算)。  
**自检：** 训练时必须真的从 0 加噪到 \(t\) 吗？

## 3. 贝叶斯反向、sigma 与生成

### 反向均值为什么是复杂公式？

**最短回答：** 它来自高斯前向过程的贝叶斯后验；先由网络预测噪声得到 \(\hat x_0\)，再代入 \(q(x_{t-1}\mid x_t,x_0)\) 的均值并整理。  
**为什么：** 生成时没有真实 \(x_0\)，只能用 \(\epsilon_\theta\) 间接估计。  
**完整复习：** [贝叶斯后验](../01_foundations/02_ddpm_from_intuition_to_formula.md#8-贝叶斯公式如何得到反向后验) 和 [均值推导](../01_foundations/02_ddpm_from_intuition_to_formula.md#10-反向均值公式逐步推导)。  
**自检：** 反向公式外的 \(1/\sqrt{\alpha_t}\) 能省掉吗？

### \(\sigma_t\) 从哪里来？\(\mu_\theta\) 与样本一样吗？

**最短回答：** 后验是高斯分布；\(\mu_\theta\) 是中心，\(\sigma_t\) 是标准差，具体样本是 \(\mu_\theta+\sigma_tz\)。  
**为什么：** \(\tilde\beta_t\) 是方差，\(\sigma_t=\sqrt{\tilde\beta_t}\) 才是标准差；最后一步常令 \(z=0\)。  
**完整复习：** [sigma 的来源](../01_foundations/02_ddpm_from_intuition_to_formula.md#11-sigma_t-从哪里来)。  
**自检：** 只使用 \(\mu_\theta\) 时，反向分布哪一部分消失？

### DDPM 为什么能生成？

**最短回答：** 网络学会把不同噪声等级的样本往数据高概率区域修正；生成从纯高斯噪声开始，反复小步去噪。  
**为什么：** 它学的不是一张图的倒放，而是把噪声向数据分布移动的局部规律。  
**完整复习：** [为什么能生成](../01_foundations/02_ddpm_from_intuition_to_formula.md#19-ddpm-为什么能够生成新样本)。  
**自检：** 生成时需要真实 \(x_0\) 吗？

## 4. 日程、DDIM、条件动作扩散

### 噪声日程和 square cosine 是什么？

**最短回答：** 日程是预先确定的 \(\beta_k,\alpha_k,\bar\alpha_k\) 表；square cosine 用平滑余弦平方曲线规定累计噪声比例。  
**为什么：** 日程不是实际抽到的 \(\epsilon\)，也不是网络输出；它控制不同扩散等级的难度。  
**完整复习：** [噪声日程](../01_foundations/02_ddpm_from_intuition_to_formula.md#21-噪声日程与-iddpm-的-square-cosine-schedule)。  
**自检：** \(\beta_k\) 是一张噪声图吗？

### DDIM 为什么能跳步？它和 DDPM 不一样吗？

**最短回答：** 两者通常共享同一个噪声预测网络；DDIM 先估计干净样本，再按目标等级系数重新混合，可跳过中间等级。  
**为什么：** 它利用前向闭式的“干净部分 + 噪声部分”结构，而非每次相邻后验随机抽样。  
**完整复习：** [DDPM 与 DDIM](../01_foundations/02_ddpm_from_intuition_to_formula.md#22-ddpm-与-ddim同一训练目标不同采样路径)。  
**自检：** 换 DDIM 是否一定要重训网络？

### 整个 Policy 流程还是 DDPM 吗？随机动作会直接执行吗？

**最短回答：** 是条件 DDPM 的动作版本：样本换为动作计划 \(A\)，观察 \(O\) 作条件。随机 \(A_t^K\) 只是规划起点，去噪完成后才执行 \(A_t^0\) 的前段。  
**为什么：** 观察已知而动作计划未知，所以只对动作加噪。  
**完整复习：** [完整流程](../02_paper_study/01_problem_and_full_pipeline.md#9-一次训练与一次控制按时间顺序串起来)。  
**自检：** 训练时和推理时的 \(A_t^0\) 分别来自哪里？

## 5. KL、EBM 与 score

### KL 散度是额外训练损失吗？

**最短回答：** KL 衡量两个概率分布的差异，在 DDPM 推导中说明模型反向分布应逼近真实后验；实践通常显式优化已注入噪声的 MSE。  
**为什么：** KL 不是一条真实动作数据，也不必意味着每轮另加独立 KL 项。  
**完整复习：** [KL 的角色](../02_paper_study/02_action_diffusion_and_formulas.md#11-kl-散度在推导中衡量两个分布差多少)。  
**自检：** KL 的输入是单个动作还是两个分布？

### score 是哪个阶段的东西？为什么要除以平方根？

**最短回答：** score 是采样时指向更高条件动作密度的方向；高斯残差 \(y-\mu=\sigma\epsilon\)，而 score 是 \(-(y-\mu)/\sigma^2\)，所以是 \(-\epsilon/\sigma\)。  
**为什么：** 在扩散等级 \(k\)，\(\sigma=\sqrt{1-\bar\alpha_k}\)。网络输出单位噪声，除以尺度才转成动作坐标上的密度斜率。  
**完整复习：** [score 推导](../02_paper_study/02_action_diffusion_and_formulas.md#13-score不是训练参数梯度而是采样时的动作方向)。  
**自检：** \(\nabla_\theta L\) 和 \(\nabla_A\log p(A\mid O)\) 对谁求导？

### EBM 为什么会被比较？

**最短回答：** EBM 用低能量表示合理动作，但归一化常数、负样本或高维搜索可能困难；扩散可直接预测已知注入噪声。  
**为什么：** 论文是在解释训练稳定性差异，不是在说 EBM 永远不能用。  
**完整复习：** [EBM 对比](../02_paper_study/02_action_diffusion_and_formulas.md#14-ebm-对比与控制理论小节)。  
**自检：** EBM 能量与 RL 奖励必然是同一个量吗？

## 6. 控制、视觉和工程

### 为什么预测长序列，却只执行前一小段？

**最短回答：** 长计划保持时间一致性；只执行前 \(T_a\) 步后重新观察，能纠正环境变化和误差。这是滚动时域控制。  
**为什么：** 全部执行是开环；只预测单步又可能缺少协调。  
**完整复习：** [RHC](../01_foundations/03_robot_control_and_rl.md#1-读论文前必须会的机器人控制)。  
**自检：** \(T_p\) 和 \(T_a\) 为什么不能无限增大？

### warm start 怎样参考未执行动作？

**最短回答：** 可用上轮未执行尾部辅助下轮初始化，但论文不把具体数组拼接/加噪方式定义为唯一公式。  
**为什么：** 新观察仍会参与重新去噪，不能开环照搬旧计划。  
**完整复习：** [设计边界](../02_paper_study/03_control_network_and_design.md#14-三项容易误读的设计选择)。  
**自检：** 论文是否写明了唯一 warm-start 数组操作？

### 多相机、多帧与状态怎样拼接？FiLM 和 Transformer 怎样条件化？

**最短回答：** 每张图先编码为向量，再与状态在特征维拼接；FiLM 用观察生成特征缩放/偏移，Transformer 用条件 token 或 cross-attention。  
**为什么：** 这不是直接把图片相加，也不是把观察本身作为要去噪的变量。  
**完整复习：** [观察数据流](../02_paper_study/03_control_network_and_design.md#11-观察动作和网络一条完整数据流) 与 [FiLM/Transformer](../02_paper_study/03_control_network_and_design.md#12-filmtransformer-和条件怎样进去)。  
**自检：** 两个 64 维相机特征和 10 维状态拼接后有多少维？

### 在线模型、EMA、BatchNorm、GroupNorm 为什么容易冲突？

**最短回答：** 在线模型是刚更新的权重，EMA 是历史平滑权重；BatchNorm 保存批次运行统计，可能不匹配 EMA 权重；GroupNorm 不依赖该运行统计。  
**为什么：** 推理权重与统计来自不同时间的模型会造成不稳定。  
**完整复习：** [EMA 与归一化](../02_paper_study/03_control_network_and_design.md#13-在线模型emabatchnorm-与-groupnorm)。  
**自检：** GroupNorm 的关键优势是没有哪一种统计？

## 7. 实验、附录与代码

### 什么是消融实验？论文实验能说明什么？

**最短回答：** 消融是在其他条件尽量不变时只改一个因素；它支持特定任务、数据和协议下的结论，而非普遍保证。  
**为什么：** 总分高不能说明提升来自视觉、时域还是采样器。相对提升 46.9% 不是每个任务加 46.9 个百分点。  
**完整复习：** [实验与附录](../02_paper_study/04_experiments_appendix_limits.md#12-按论文顺序回顾每组实验要证明什么)。  
**自检：** 真实机器人成功率高能直接推出“已经安全”吗？

### 归一化、6D 旋转、图像增强为何重要？

**最短回答：** 它们让动作表示连续、数值尺度适合训练、视觉不只死记背景像素。  
**为什么：** 扩散直接操作动作张量；表示和尺度会影响训练、采样与控制。  
**完整复习：** [附录实现细节](../02_paper_study/04_experiments_appendix_limits.md#13-附录实现细节为何会影响结果)。  
**自检：** 6D rotation 是六维位置吗？

### 论文符号怎样映射到官方代码？

**最短回答：** \(T_o,T_a,T_p\) 对应常见代码名 n_obs_steps、n_action_steps、horizon；数据依次经过 normalizer、编码器、噪声预测器、scheduler、执行切片与环境评估。  
**为什么：** 先建立映射和张量形状，才能读懂实现而不迷失在网络细节。  
**完整复习：** [论文到官方代码](../03_code_and_practice/01_paper_to_official_code.md)。  
**自检：** horizon 是观察长度、执行长度还是完整预测计划长度？

## 最后一条检查

若某个疑问不在这里，先把它改写成“哪个变量、哪个阶段、哪个因果关系不清楚”，再在符号卡和学习地图中定位；这比重复背整页公式更有效。

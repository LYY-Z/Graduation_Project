# 符号表与公式卡

## 核心术语

| 英文 | 建议中文 | 在本文中的意思 |
|---|---|---|
| policy | 策略 | 从观测生成机器人动作的规则/模型。 |
| visuomotor policy | 视觉-运动策略 | 输入含相机图像（可含本体状态），输出机器人动作。 |
| imitation learning / behavior cloning | 模仿学习 / 行为克隆 | 用专家演示作监督数据，学习“观测到动作”的映射。 |
| diffusion model | 扩散模型 | 训练时逐步加噪、学习反向去噪的生成模型。 |
| DDPM | 去噪扩散概率模型 | 本文使用的扩散模型家族。 |
| conditional | 条件化 | 在生成动作时显式输入观测特征 $O_t$。 |
| multimodal | 多模态（多峰） | 同一观测下有多种合理动作，例如从物体左或右绕过去。它不是“文字+图像的多模态”。 |
| score function | 得分函数 | 对变量求梯度的对数概率密度，指向更高概率区域。 |
| denoising | 去噪 | 把噪声样本一步步变成符合数据分布的样本。 |
| receding-horizon control | 滚动时域控制 | 预测较长动作序列，但仅执行前段，随后用新观测再预测。 |
| observation horizon | 观测历史长度 | $T_o$，模型每次查看最近多少时刻的观测。 |
| action horizon | 动作执行长度 | $T_a$，每次规划后真正执行多少动作。 |
| prediction horizon | 动作预测长度 | $T_p$，每次完整生成的未来动作数量。 |
| FiLM | 特征逐通道线性调制 | 用条件特征缩放/平移网络特征的方式。 |
| spatial softmax | 空间 softmax | 从特征图提取具有空间位置敏感性的特征。 |
| GroupNorm | 组归一化 | 在通道组内做归一化；对小 batch/EMA 更稳。 |
| DDIM | 去噪扩散隐式模型 | 可把推理去噪步数减少而无需重新训练的采样方法。 |
| end-to-end | 端到端训练 | 视觉编码器和动作生成网络一起根据最终训练损失更新。 |

## 论文符号

| 符号 | 意义 | 初学者读法 |
|---|---|---|
| $t$ | 控制时刻 | 机器人当前第 $t$ 次决策。 |
| $k$ | 扩散/去噪迭代编号 | 一次动作生成内部的第 $k$ 步；不要和 $t$ 混淆。 |
| $O_t$ | 当前观测窗口 | 最近 $T_o$ 帧图像/状态。 |
| $A_t^0$ | 干净的目标动作序列 | 数据集中真实示范或最终去噪结果。 |
| $A_t^k$ | 第 $k$ 个噪声级别的动作序列 | 随 $k$ 增大，通常越接近噪声。 |
| $K$ | 去噪总步数 | 训练或推理要经过的扩散步数。 |
| $\epsilon_\theta$ | 噪声预测网络 | 参数为 $\theta$ 的神经网络；论文的核心可学习函数。 |
| $\epsilon^k$ | 人为加入的高斯噪声 | 训练目标，不是网络参数。 |
| $\alpha,\gamma,\sigma$ | 噪声调度参数 | 控制每步保留、校正和扰动的尺度。 |
| $p(A_t\mid O_t)$ | 条件动作分布 | 给定观测后，不同未来动作序列的可能性。 |
| $\mathrm{MSE}$ | 均方误差 | 预测噪声与真实噪声之差的平方平均。 |

## 最容易混淆的三组概念

1. **动作时间 $t$ 与扩散步 $k$：** $t$ 发生在真实机器人控制循环；$k$ 是生成一次动作序列时的内部迭代。
2. **多模态与多模态感知：** 这里是概率分布存在多个峰；不是图像、语言、力觉等多种传感器。
3. **预测长度 $T_p$ 与执行长度 $T_a$：** 前者是模型输出多远，后者是机器实际走几步；通常 $T_a < T_p$。

## 公式卡：先看角色，再看系数

| 公式 | 用在何时 | 它在做什么 | 不要误解为 |
|---|---|---|---|
| \(x_k=\sqrt{\bar\alpha_k}x_0+\sqrt{1-\bar\alpha_k}\epsilon\) | 训练造带噪样本 | 按方差正确比例混合干净数据和已知噪声 | 必须逐步执行 \(k\) 次加噪 |
| \(\epsilon_\theta(x_k,k)\approx\epsilon\) | 训练目标 | 预测已注入的标准噪声 | 直接输出干净图片或动作 |
| \(\hat x_0=(x_k-\sqrt{1-\bar\alpha_k}\epsilon_\theta)/\sqrt{\bar\alpha_k}\) | 推理中间估计 | 由当前样本和预测噪声反推干净样本 | 最终一定真实等于 \(x_0\) |
| \(x_{k-1}=\mu_\theta+\sigma_kz\) | DDPM 采样 | 从反向高斯分布得到上一级样本 | \(\mu_\theta\) 就等于样本 |
| \(A_t^k=\sqrt{\bar\alpha_k}A_t^0+\sqrt{1-\bar\alpha_k}\epsilon\) | Policy 训练 | 对专家动作计划加噪 | 对观察图片也加噪 |
| \(\hat s_\theta=-\epsilon_\theta/\sqrt{1-\bar\alpha_k}\) | score 关系 | 单位噪声预测转为动作密度方向 | 对模型参数做梯度下降 |

## 变量的实际形状卡

| 变量 | 示例形状 | 阶段 | 不要混淆 |
|---|---|---|---|
| \(O_t\) | 图像 batch 加本体状态特征 | 训练与推理 | 不是待生成动作 |
| \(A_t^0\) | \(B,T_p,D_a\) | 训练真值 / 推理输出 | 不是单个 \(a_t\) |
| \(A_t^k\) | \(B,T_p,D_a\) | 扩散内部 | 不是现实第 \(k\) 步 |
| \(\epsilon,z\) | 与 \(A\) 或 \(x\) 同形状 | 前向训练 / 反向采样 | 分布相似但角色不同 |
| \(k\) | 每 batch 一个扩散等级 | 去噪内部 | 不是现实控制时刻 \(t\) |
| \(T_o,T_a,T_p\) | 三个小整数 | 控制设计 | 不是扩散步数 \(K\) |

## 二、总判定：未覆盖（局部近邻，需有区别地表述）

没有任何一篇同时做到：悬空辨识含轮（速度损失）+ 着地后用车辆动力学少参数轮-地模型（滚动阻力、载荷相关、有效半径/滑移）拟合 + 以汽车标准试验评价 + 与 DR/只辨识/残差执行器受控比较。

剩余真实差异：
1. 轮-地用**物理可解释的车辆参数**（c0、c1、有效半径、侧偏/滑移）实机拟合并回灌仿真训练；论文 2 的刚度是手填常数，论文 3 为黑箱残差，论文 1/6 是足-土而非轮-胎。
2. 标准操纵试验（稳态回转、横摆阶跃、低附着加速）作为 sim-to-real 评价指标：论文 2/3 只用圈速类指标。
3. 受控消融：DR / 只辨识 / 残差执行器 / 本方法同一管线比较，无人做过。

最接近的是论文 2（同平台同方向，作者来自 Borrelli 组，后续很可能补轮胎建模）；风险是时效，不是现有重叠。

## 四、核实

**A. Isaac Sim / Isaac Lab 实现路径：可行，但只能走外力/力矩路线**
- PhysX 5 材质（PxMaterial）只有静/动摩擦、恢复系数、阻尼与 eDISABLE_FRICTION / eDISABLE_STRONG_FRICTION 等标志；头文件中无各向异性摩擦、无滚动阻力、无扭转摩擦。证据：https://raw.githubusercontent.com/NVIDIA-Omniverse/PhysX/main/physx/include/PxMaterial.h ；https://nvidia-omniverse.github.io/PhysX/physx/5.4.1/_api_build/classPxMaterial.html 。故不能靠材质表达 (2)。
- Isaac Lab 可施加自定义力：Articulation.set_external_force_and_torque(forces, torques, positions, body_ids, env_ids, is_global)，缓冲后在 write_data_to_sim 中经 apply_forces_and_torques_at_position 逐物理步施加。证据：https://github.com/isaac-sim/IsaacLab/blob/v2.2.0/source/isaaclab/isaaclab/assets/articulation/articulation.py 。注意：较新版本（0.54.4，2026-06）已弃用，改用 set_forces_and_torques() 与 wrench composer（https://docs.nvidia.com/isaaclab/2.2/references/extensions-changelog.md ，经搜索摘要得知，未逐字核对新 API 签名，实施时需看对应版本文档）。
- 推荐实现：每步读轮速、法向载荷（接触力传感器）、车体速度，按模型算纵向/侧向力与滚动阻力矩，作为外力施加于轮体（或关节力矩补偿）；滚动阻力矩可直接叠加在轮关节 effort 上。PhysX 车辆 SDK 有轮胎摩擦-滑移曲线与载荷相关侧偏刚度（https://nvidia-omniverse.github.io/PhysX/physx/5.3.0/docs/Vehicles.html ），但其面向轮式车辆实体，不适配关节轮足，未验证可用性，不建议依赖。
- 同类做法佐证：论文 1 摘要称向标准刚性接触仿真器“注入”足-土力。

**B. Go2-W 轮子无转向自由度：成立**
- 论文 2 明确写“The Go2-W has no steered wheels so yaw is generated by differential wheel torque (skid-steering)”，并有 12 关节 + 4 轮 = 16 驱动（arXiv:2606.26313）。
- 宇树官网：16 个关节电机、轮毂电机、7 英寸充气轮胎（https://unitree.com/go2-w ），页面未提转向。结论：转弯靠左右差速（侧滑转向）；每条腿仍有 3 个腿关节可改变轮位姿，但轮本身无转向轴。充气胎意味着滚动阻力与有效半径随载荷/气压变化，对 (2) 有利。
